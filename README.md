# Notatki z lekcji Git

![Avatar](./avatar-Git_basic.png)

Repozytorium zawiera moje notatki z zajęć o Git i GitHub, w tym podstawy, branche, pull requesty i zarządzanie repozytoriami zdalnymi.  

---

## Spis treści

1. [Podstawy Git](lekcja1-podstawy.md) – czym jest Git, repozytoria i commity  
2. [Branch](lekcja2-branch.md) – praca na branchach, znaczenie branchy  
3. [Pull Request](lekcja3-pull-request.md) – jak tworzyć i scalać Pull Requesty  
4. [Commit](lekcja4-commit.md) – dobre praktyki commitów  
5. [Repozytoria zdalne](lekcja5-zdalne.md) – współpraca i push/pull na GitHub

## Jak korzystać

- Kliknij na plik `.md`, żeby zobaczyć notatki z danej lekcji  
- Pobierz repozytorium lokalnie: **Code → Download ZIP**  
- Dla chętnych: repo zawiera branch `notatki-rozszerzenie` z przykładem Pull Request  

---

## Technologie

- Git – system kontroli wersji  
- GitHub – hosting repozytoriów zdalnych  
- Markdown – formatowanie notatek  

---

## Komendy Git w skrócie

| Komenda | Opis |
|---------|------|
| `git init` | Tworzy nowe repozytorium |
| `git add` | Dodaje pliki do stage |
| `git commit` | Zapisuje zmiany w historii |
| `git branch` | Tworzy/wyświetla branche |
| `git merge` | Scala branche |
